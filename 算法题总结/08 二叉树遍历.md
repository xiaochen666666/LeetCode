## 用递归按左 → 根 → 右访问

每次调用处理一棵子树。空树直接返回，非空时等左子树处理完成，再记录根节点，然后处理右子树。复用时由入口创建结果列表，再传给所有递归调用。要写前序或后序，只需把记录根节点的语句分别移到两次子调用之前或之后。

```java
private void inorder(TreeNode node, List<Integer> result) {
    if (node == null) {
        return;
    }
    inorder(node.left, result);
    result.add(node.val);
    inorder(node.right, result);
}
```

时间 O(n)，递归栈空间 O(h)，其中 h 为树高。

## 用显式栈写中序迭代

向左走时把节点压栈，走到空位置后弹出并访问栈顶，然后转到右子树。栈里仍有节点，或手上还有子树待处理时，都继续循环。`ArrayDeque` 的 `push` 和 `pop` 对应栈顶入栈与出栈。

```java
Deque<TreeNode> pending = new ArrayDeque<>();
TreeNode current = root;
while (current != null || !pending.isEmpty()) {
    while (current != null) {
        pending.push(current);
        current = current.left;
    }
    current = pending.pop();
    result.add(current.val);
    current = current.right;
}
```

在入口创建 `List<Integer> result`。时间 O(n)，显式栈占 O(h) 空间。

## 从左右子树的返回值求高度

先问清递归的返回值代表什么。这里每次调用返回当前子树的高度，按节点数计算。空子树返回 `0`，收到两个子树高度后取较大的一个，再加上当前节点。这种写法在左右子树都处理完后再计算当前节点的结果。

```java
int height(TreeNode node) {
    if (node == null) {
        return 0;
    }
    int leftHeight = height(node.left);
    int rightHeight = height(node.right);
    return Math.max(leftHeight, rightHeight) + 1;
}
```

时间 O(n)，递归栈空间 O(h)，其中 h 为树高。

如果当前节点需要知道从整棵树的根走了多远，可以改用自顶向下的 DFS。把路径上的节点数作为参数传给两个孩子，并在进入每个非空节点时更新最大值。以同一个节点为例，自底向上的返回值描述它下面的子树，自顶向下的参数描述到达它之前的路径。

## 递归中交换左右子树

翻转二叉树时，当前层交换的是两个孩子的引用，递归负责翻转两个孩子各自的内部。可以先交换再处理换边后的两棵子树，也可以先处理原来的两棵子树再交叉接回。若要连续改写两个引用，先保存仍会用到的原引用。

## 成对递归检查镜像

让递归参数表示一对镜像位置。先检查两边的空缺和节点值，再递归比较 `(a.left, b.right)` 与 `(a.right, b.left)`。两个子问题都成立时，当前这对子树才对称。

改写成迭代时，用队列保存待比较的节点对。每次取出一对，空位置或节点值不匹配时直接结束。需要继续比较孩子时，把外侧、内侧两个对子分别追加到队尾。

[101. 对称二叉树](../对称二叉树.md)

## 后序递归同时计算向下路径和最长路径

对子树递归时，返回能继续接到父节点的一条向下路径。在当前节点，可以用左右两条向下路径更新全树答案。第 543 题中，递归返回的是按节点数计算的高度，更新答案用的是按边数计算的路径长度。

## 用队列按层访问

每轮开头记录 `levelSize = queue.size()`，内层固定出队 `levelSize` 次。先把左孩子加入队尾，再加入右孩子。用新列表收集每层的值。当前层出队完毕后，队列恰好是下一层。

也可以用两个列表分层。遍历 `currentLevel` 时只向 `nextLevel` 追加孩子，遍历完才切换到下一层。用一个队列时，待处理的本层节点和已收集的下一层节点分别位于队列前部和后部。

用 DFS 收集层序结果时，把深度作为参数传给孩子。第一次到达某层时创建列表，然后将值追加到深度对应的位置。先处理左子树，再处理右子树，同层的值就会按从左到右的顺序追加。

## 从有序区间递归建平衡搜索树

递归接收闭区间并返回子树根。取中间值建节点，把 `[left, mid - 1]` 与 `[mid + 1, right]` 的结果分别接到左右两边。只有 `left > right` 时才返回空节点。

[108. 将有序数组转换为二叉搜索树](../将有序数组转换为二叉搜索树.md)

使用左闭右开区间时，入口为 `[0, nums.length)`，空区间条件为 `left == right`，左右子区间分别为 `[left, mid)`、`[mid + 1, right)`。

## 递归传递祖先留下的取值范围

检查 BST 时，让每次调用携带允许的开区间 `(low, high)`。当前值通过检查后，左边只更新上界，右边只更新下界。初始范围要能容纳节点值的全部取值。

同一题也可以先走左侧，在中序访问时用上一个值检查严格递增；或者先处理完左右孩子，在后序位置用左侧最大值和右侧最小值检查当前节点。

[98. 验证二叉搜索树](../验证二叉搜索树.md)

## 中序遍历按排名提前停止

把计数更新放在左子树返回之后、右递归之前。命中后可以用共享状态告诉上一层停止，也可以直接把答案作为递归返回值向上传。采用返回值时，提前确定一个能与真实节点值区分的未命中标记。
