## 相似写法怎么选

| 容易混淆的场景 | 决定写法的那个问题 |
| --- | --- |
| 排序链表 / 回文链表 | 对四个节点，切左半段要停在第 2 个，拿右半段去比较要从第 3 个开始。 |
| 两数之和 / 和为 K 的子数组 | 查到历史项后，要返回它的下标，还是要把它出现的次数全加进答案？ |
| 最长无重复 / 最小覆盖 | 当前窗口合法时，前者记录长度后继续扩展，后者记录长度后继续缩短。 |
| 盛最多水的容器 / 接雨水 | 前者用两端高度计算整对容器的面积，后者判断某格水位后把这一格的水量累加。 |
| 滑动窗口最大值 / 接雨水的单调栈 | 最大值候选会从窗口左端过期，需要双端队列；计算凹槽时只需要查看和弹出栈顶。 |

## 把几步拼成一道题

- **排序链表**：找左中点 → 保存右段头并断链 → 递归排好两段 → 尾插合并。
- **回文链表**：找右半段起点 → 反转后半段 → 从头和新段头逐值比较。需要保留链表结构时，比较结束后把后半段反转回来。
- **K 个一组翻转**：从组前驱数够 k 个 → 反转到组外后继为止 → 接回新组头 → 原组头成为下一组前驱。

Java 片段放在题目的类内使用。集合类可用 `import java.util.*;`，普通链表沿用力扣的 `ListNode`。第 138 题的随机节点和第 146 题的双向节点分别使用各题定义。各节以原题的输入约束为前提。
