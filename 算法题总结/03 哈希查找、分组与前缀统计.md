## 当前值确定另一半，先查询再登记

遍历到 x 时，之前出现过 target - x 就能配成一对。以 [3,3]、目标 6 为例，在第二个 3 才能查到第一个下标。先登记可能让当前位置和自己配对。哈希操作平均 O(1)，全程平均 O(n)。

```java
public int[] twoSum(int[] nums, int target) {
    HashMap<Integer, Integer> map = new HashMap<>();
    for (int i = 0; i < nums.length; i++) {
        int complement = target - nums[i];
        if (map.containsKey(complement)) {
            return new int[] { map.get(complement), i };
        }
        map.put(nums[i], i);
    }
    return new int[0];
}
```

## 构造统一的键，把原元素追加到组中

eat、tea 排序后都是 aet；aab 与 abb 排序后不同，重复次数得以保留。排序后的字符串只用作键，列表中追加原词。computeIfAbsent 在键缺失时建列表，并返回这个键对应的列表，已有组也可以直接追加。单词长度 L 时，生成排序键需要 O(L log L)。

```java
List<List<String>> groupAnagrams(String[] words) {
    Map<String, List<String>> groups = new HashMap<>();
    for (String word : words) {
        char[] letters = word.toCharArray();
        Arrays.sort(letters);
        String key = new String(letters);
        groups.computeIfAbsent(key, unused -> new ArrayList<>()).add(word);
    }
    return new ArrayList<>(groups.values());
}
```

## 只从连续段的起点向后数

先去重。遇到 3 时，如果 2 已在集合中，起点一定在更左边；只有 x-1 缺席才扩展。遍历集合可以避免重复起点反复展开。每个不同元素最多参与一次向后扩展，平均 O(n)。代码中的 x±1 在本题数值范围内安全。

```java
public int longestConsecutive(int[] nums) {
    Set<Integer> set = new HashSet<>();
    for (int num : nums) {
        set.add(num);
    }

    int res = 0;
    for (int x : set) {
        if (!set.contains(x - 1)) {
            int current = x;
            int length = 1;

            while (set.contains(current + 1)) {
                current++;
                length++;
            }

            res = Math.max(res, length);
        }
    }
    return res;
}
```

## 前缀差转成历史次数

求连续区间和时，把区间写成当前前缀和减去某个更早的前缀和。历史中 sum-k 每出现一次，就多一个起点。令空前缀 0 先出现一次；每轮先查再加。对 [0,0] 和 k=0，两轮各贡献 1、2，答案是 3。含负数时这个关系仍成立。

```java
public int subarraySum(int[] nums, int k) {
    Map<Integer, Integer> map = new HashMap<>();
    int sum = 0;
    int res = 0;

    // 初始化哈希表
    map.put(0, 1);
    for (int x : nums) {
        // 更新前缀和
        sum += x;
        // 累加答案
        res += map.getOrDefault(sum - k, 0);
        // 记录当前前缀和
        map.put(sum, map.getOrDefault(sum, 0) + 1);
    }

    return res;
}
```
