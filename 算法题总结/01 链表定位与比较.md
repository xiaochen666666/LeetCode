先确定要停在哪个节点。找左中点、找后半段起点、找倒数节点的前驱，三者都用两个指针，但起点和停止条件不同。下面的方法都放在 Solution 类中，ListNode 沿用力扣定义。

## 找左中点，切开两段

从 1 → 2 → 3 → 4 切出两段，左段应该停在 2。让 fast 从第二个节点起跑，slow 从第一个节点起跑。长度为 5 时 slow 停在 3。分割时先保存 mid.next，再令 mid.next = null；排序递归在长度小于 2 时直接返回。拿 2 → 1 试一次就知道为什么必须让子问题变短。时间 O(n)，额外空间 O(1)。

```java
ListNode leftMiddle(ListNode head) {
    if (head == null) return null;
    ListNode slow = head;
    ListNode fast = head.next;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }
    return slow;
}
```

## 找右半段起点，奇数跳过正中间

若要从链表两端比较，奇数长度时中间节点没有搭档。让 fast、slow 同时从 head 出发。偶数长度时 fast 到 null，slow 已在右中点；奇数长度时 fast 停在尾节点，slow 再走一步。对 1 → 2 → 2 → 1 返回第三个节点，对 1 → 2 → 3 → 2 → 1 返回第四个节点。随后反转返回的半段，从 head 与反转后的头逐值比较，后半段走完即结束。

```java
ListNode secondHalfStart(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }
    return fast == null ? slow : slow.next;
}
```

## 用固定间距找待删节点的前驱

删除某节点需要改它前一个节点的 next。两指针从 dummy 出发，fast 先走 n 步，之后同步走，直到 fast 停在尾节点。对 1 → 2 → 3 → 4 → 5，n = 2 时 slow 停在 3。n 等于链长时 slow 留在 dummy，一样可以删除头节点。前提为 1 ≤ n ≤ 链长。

```java
public ListNode removeNthFromEnd(ListNode head, int n) {
    ListNode dummy = new ListNode();
    dummy.next = head;
    ListNode fast = dummy;
    ListNode slow = dummy;

    for (int i = 0; i < n; i++) {
        fast = fast.next;
    }

    while (fast.next != null) {
        fast = fast.next;
        slow = slow.next;
    }

    slow.next = slow.next.next;
    return dummy.next;
}
```

## 先判环，再找环的入口

同一起点出发，先移动再比较节点引用。两者进入环后，每轮相对距离变化一格，终会相遇。要找入口，设头到入口为 a 步，入口到相遇点为 b 步；快指针多走了整数圈，也恰好多走了慢指针走过的 a+b 步，所以从相遇点再走 a 步会回到入口。此时让新指针从头出发，与慢指针同速即可。只判有没有环时，在第一次相遇处返回 true。

```java
public ListNode detectCycle(ListNode head) {
    ListNode fast = head;
    ListNode slow = head;
    ListNode p = head;
    while (fast != null && fast.next != null) {
        fast = fast.next.next;
        slow = slow.next;
        if (slow == fast) {
            while (p != slow) {
                p = p.next;
                slow = slow.next;
            }
            return p;
        }
    }
    return null;
}
```

## 换链对齐长度，判断同一个节点

适用于两条无环链表。A 的指针到 null 就换到 B 的头，另一个反向换。若两段独有前缀一样长，会在第一遍相遇；否则换链后，两者到公共尾段之前都走过了两条独有前缀和一遍公共段。两个值都为 8 的不同节点不算相交，比较的是引用。无交点时共同停在 null。

```java
public ListNode getIntersectionNode(ListNode headA, ListNode headB) {
    ListNode pA = headA;
    ListNode pB = headB;
    while (pA != pB) {
        if (pA == null) {
            pA = headB;
        } else {
            pA = pA.next;
        }
        if (pB == null) {
            pB = headA;
        } else {
            pB = pB.next;
        }
    }
    return pA;
}
```
