## 反转一段，指定停止位置

把范围写成左闭右开 [first, stop)，stop 必须从 first 沿 next 可达，也可以是链尾后的 null。prev 从 stop 开始，旧段头第一轮就接到后继。整条反转时传入 head 和 null；分组时先确认够 k 个，再传入组头和组后继。返回新段头，调用方把前驱接过去。每个节点只改一次 next。

```java
ListNode reverseUntil(ListNode first, ListNode stop) {
    ListNode prev = stop;
    ListNode current = first;
    while (current != stop) {
        ListNode next = current.next; // 改指向之前，保留向前走的路
        current.next = prev;
        prev = current;
        current = next;
    }
    return prev;
}
```

## 每 k 个为一组，反转后接回两端

在整链反转的基础上加三步：先数够 k 个，再记住下一组起点，翻完把上一组尾接到新头。以 1 → 2 → 3 → 4、k=3 为例，stop 是 4，reverseUntil 返回 3，原组头 1 变成下一组的前驱。最后不足 k 个时直接保留。下例调用上一节的方法，前提是 k ≥ 1。

```java
ListNode reverseKGroup(ListNode head, int k) {
    ListNode dummy = new ListNode(0, head);
    ListNode before = dummy;
    while (true) {
        ListNode end = before;
        for (int i = 0; i < k; i++) {
            end = end.next;
            if (end == null) return dummy.next;
        }
        ListNode first = before.next;
        before.next = reverseUntil(first, end.next);
        before = first;
    }
}
```

## 交换相邻两节点，接好三条边

画出 before → a → b → after，目标为 before → b → a → after。先让 a 指向 b 原来的后继，再让 b 指回 a。a 成为组尾，正好是下一组的前驱。剩单节点时循环自然结束。

```java
ListNode swapPairs(ListNode head) {
    ListNode dummy = new ListNode(0, head);
    ListNode before = dummy;
    while (before.next != null && before.next.next != null) {
        ListNode a = before.next;
        ListNode b = a.next;
        a.next = b.next;
        b.next = a;
        before.next = b;
        before = a;
    }
    return dummy.next;
}
```

## 尾插法合并两个有序链表

两条升序链表各自最小的剩余元素都在头部。tail 指向已经接好的最后一个节点；每次选一个头，移动被选链表，再前移 tail。遇到相等值先选左侧可保持稳定。一方用完，另一方整段接上。用 a = 1 → 4、b = 2 → 3 手推，最后一次只需把 4 接上。时间 O(m+n)，额外空间 O(1)，复用原节点。

```java
public ListNode mergeTwoLists(ListNode list1, ListNode list2) {
    ListNode dummy = new ListNode(0);
    ListNode tail = dummy;
    while (list1 != null && list2 != null) {
        // 比较两个当前节点的值
        if (list1.val <= list2.val) {
            tail.next = list1;
            list1 = list1.next;
        } else {
            tail.next = list2;
            list2 = list2.next;
        }
        tail = tail.next;
    }
    if (list1 != null) {
        tail.next = list1;
    } else {
        tail.next = list2;
    }
    return dummy.next;
}
```

## 把中点、断链、合并拼成归并排序

无序单链表要先拆到单节点，然后合并已排好的两半。下例调用第 01 篇的 leftMiddle 和本篇的 mergeTwoLists。若输入已经是 k 条有序链，直接两两合并，每轮组距按 1、2、4 翻倍，奇数条时最后一条留给下一轮。前者时间 O(n log n)、栈 O(log n)，后者总节点数 N 时，k ≥ 2 的时间为 O(N log k + k)。

```java
ListNode sortList(ListNode head) {
    if (head == null || head.next == null) return head;
    ListNode mid = leftMiddle(head);
    ListNode right = mid.next;
    mid.next = null;
    return mergeTwoLists(sortList(head), sortList(right));
}
```

## 多路归并，用最小堆选下一个节点

两条链可以直接比较头节点；有 k 条链时，把每条非空链的当前头放进最小堆。弹出最小节点后，只需把它的后继加入堆。这样任一时刻同一条链最多占一个位置。Comparator.comparingInt 按节点值排序，poll 取出当前最小值。输入链表互不共享节点。

```java
ListNode mergeKLists(ListNode[] lists) {
    PriorityQueue<ListNode> heads = new PriorityQueue<>(
        Comparator.comparingInt(node -> node.val)
    );
    for (ListNode first : lists) {
        if (first != null) heads.offer(first);
    }
    ListNode dummy = new ListNode(0);
    ListNode tail = dummy;
    while (!heads.isEmpty()) {
        ListNode smallest = heads.poll();
        if (smallest.next != null) heads.offer(smallest.next);
        tail.next = smallest;
        tail = smallest;
    }
    return dummy.next;
}
```

## 用尾指针生成新链，循环带上进位

输入按个位在前存储，两边当前节点就是同一位。取出的数字和进位先相加，再分别取余、整除。9 → 9 与 1 相加会产生 0 → 0 → 1，两个输入都耗尽时还应处理最后的进位。

```java
public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
    ListNode dummy = new ListNode(0);
    ListNode tail = dummy;
    int carry = 0;

    while (l1 != null || l2 != null || carry != 0) {
        int sum = carry;
        if (l1 != null) {
            sum += l1.val;
            l1 = l1.next;
        }
        if (l2 != null) {
            sum += l2.val;
            l2 = l2.next;
        }

        tail.next = new ListNode(sum % 10);
        tail = tail.next;
        carry = sum / 10;
    }

    return dummy.next;
}
```

## 用原节点查副本，再连接任意指针

当 random 可以指向未来节点或自身时，先保证每个原节点都有唯一副本，然后统一接线。键用节点引用，值相同的两个节点也会分开复制。第二趟中 map.get(p) 表示正在接线的副本，map.get(p.random) 表示它要指向谁。平均时间 O(n)，表占 O(n)。本节 Node 采用第 138 题带 random 的定义。

```java
public Node copyRandomList(Node head) {
    HashMap<Node, Node> map = new HashMap<>();
    Node p = head;
    while (p != null) {
        Node copyP = new Node(p.val);
        map.put(p, copyP);
        p = p.next;
    }

    p = head;
    while (p != null) {
        Node copyP = map.get(p);
        copyP.random = map.get(p.random);
        copyP.next = map.get(p.next);
        p = p.next;
    }
    return map.get(head);
}
```

## 双向链表摘除节点、插到最前

哈希表按 key 找到节点后，更新使用顺序只涉及相邻节点。head、tail 是两个哨兵，空时 head.next = tail、tail.prev = head。访问已有节点就先摘再插；新节点直接插。超容量时先保存 tail.prev，从链表摘掉它，并以它的 key 删除哈希表项。这里的 Node 有 prev、next，两个方法放在持有 head 的 LRUCache 里。

```java
private void unlink(Node node) {
    node.prev.next = node.next;
    node.next.prev = node.prev;
}

private void addFirst(Node node) {
    node.next = head.next;
    node.prev = head;
    head.next.prev = node;
    head.next = node;
}
```
