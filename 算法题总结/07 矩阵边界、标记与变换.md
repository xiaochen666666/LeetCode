## 从右上角排除一行或一列

前提为各行、各列都升序。在右上角，比目标小意味着当前行其余元素都更小，向下；比目标大意味着本列其余元素都更大，向左。每轮排除一条边，最多走 m+n 步。

```java
public boolean searchMatrix(int[][] matrix, int target) {
    int rows = matrix.length;
    int cols = matrix[0].length;
    int row = 0;
    int col = cols - 1;

    while (row < rows && col >= 0) {
        int value = matrix[row][col];
        if (value < target) {
            row++;
        } else if (value > target) {
            col--;
        } else {
            return true;
        }
    }
    return false;
}
```

## 按四条边遍历剩余矩形

top、bottom、left、right 全是闭边界。走完上边就 top++，走完右边就 right--。走下边、左边前确认它们仍存在。手推单行 [1,2,3] 和单列 [1,2,3]，最后一条边不能再扫一遍。每个元素访问一次。

```java
public List<Integer> spiralOrder(int[][] matrix) {
    List<Integer> res = new ArrayList<>();
    int top = 0;
    int bottom = matrix.length - 1;
    int left = 0;
    int right = matrix[0].length - 1;

    while (top <= bottom && left <= right) {
        //向右
        for (int j = left; j <= right; j++) {
            res.add(matrix[top][j]);
        }
        top++;
        if (top > bottom)
            break;
        //向下
        for (int i = top; i <= bottom; i++) {
            res.add(matrix[i][right]);
        }
        right--;
        if (left > right)
            break;
        //向左
        for (int j = right; j >= left; j--) {
            res.add(matrix[bottom][j]);
        }
        bottom--;
        if (top > bottom)
            break;
        //向上
        for (int i = bottom; i >= top; i--) {
            res.add(matrix[i][left]);
        }
        left++;
        if (left > right)
            break;
    }
    return res;
}
```

## 把行列标记借存在首行与首列

两次扫描分别回答“哪些行列原本有零”和“现在该把哪格写零”。首行首列可借作标记，但它们原本是否有零须先独立保存。处理中间区域后再清首行首列，否则会把标记全部抹成零。时间 O(mn)，额外空间 O(1)。

```java
public void setZeroes(int[][] matrix) {
    int m = matrix.length;
    int n = matrix[0].length;
    boolean firstRowZero = false;
    boolean firstColZero = false;

    for (int i = 0; i < m; i++) {
        if (matrix[i][0] == 0) {
            firstColZero = true;
        }
    }
    for (int j = 0; j < n; j++) {
        if (matrix[0][j] == 0) {
            firstRowZero = true;
        }
    }

    for (int i = 1; i < m; i++) {
        for (int j = 1; j < n; j++) {
            if (matrix[i][j] == 0) {
                matrix[i][0] = 0;
                matrix[0][j] = 0;
            }
        }
    }
    for (int i = 1; i < m; i++) {
        for (int j = 1; j < n; j++) {
            if (matrix[i][0] == 0 || matrix[0][j] == 0) {
                matrix[i][j] = 0;
            }
        }
    }

    if (firstRowZero) {
        for (int j = 0; j < n; j++) {
            matrix[0][j] = 0;
        }
    }
    if (firstColZero) {
        for (int i = 0; i < m; i++) {
            matrix[i][0] = 0;
        }
    }
}
```

## 转置再反转每行，顺时针转九十度

沿主对角线交换后，(i,j) 到 (j,i)；再左右翻转每行，到 (j,n-1-i)。只遍历上三角 j>i，每对交换一次。用左上角试方向：旋转后应到右上角。可复用第 05 篇轮转数组的 reverse 方法。

```java
public void rotate(int[][] matrix) {
    int n = matrix.length;
    for (int i = 0; i < n; i++) {
        for (int j = i + 1; j < n; j++) {
            // 交换 matrix[i][j] 与 matrix[j][i]
            int temp = matrix[i][j];
            matrix[i][j] = matrix[j][i];
            matrix[j][i] = temp;
        }
    }
    for (int i = 0; i < n; i++) {
        int left = 0;
        int right = n - 1;
        while (left < right) {
            // 交换 matrix[i][left] 和 matrix[i][right]
            int temp = matrix[i][left];
            matrix[i][left] = matrix[i][right];
            matrix[i][right] = temp;
            left++;
            right--;
        }
    }
}
```
