## 读指针扫全数组，写指针标记下一空位

扫描到非零数就与写位置交换，写指针才前进。扫描到 0 只前进读指针。这样写指针左边始终是按原顺序出现的非零数，两个指针重合时自交换也安全。

```java
public void moveZeroes(int[] nums) {
    int left = 0;
    int right = 0;
    int n = nums.length;
    while (left < n) {
        if (nums[left] != 0) {
            int temp = nums[left];
            nums[left] = nums[right];
            nums[right] = temp;
            right++;
        }
        left++;
    }
}
```

## 从两端选容器，淘汰较短边

面积等于宽度乘两端较低高度。若保留较短的一端，向内挪另一端只会减少宽度，高度也无法超过这条短边。因此记录当前面积后移动短边即可。接雨水改为逐格累计水深，要用左右已见最高值判断哪一格可以结算。

```java
public int maxArea(int[] height) {
    int left = 0;
    int right = height.length - 1;
    int maxArea = 0;
    while (left < right) {
        int area = (right-left)*Math.min(height[left],height[right]);
        maxArea = Math.max(maxArea,area);
        if(height[left]<height[right]){
            left++;
        }
        else if(height[left]>height[right]){
            right--;
        }
        else{
            left++;
        }
    }
    return maxArea;
}
```

## 排序后固定一个数，两端逼近目标

数组有序后，和过小就增加左值，过大就降低右值。命中后跳过左右相同值，固定项也要跳过重复。例 [-2,0,0,2,2] 只产生一次 [-2,0,2]。排序会改变原下标，要求返回原下标的两数之和适合用哈希表。

```java
public List<List<Integer>> threeSum(int[] nums) {
    List<List<Integer>> res = new ArrayList<>();
    Arrays.sort(nums);
    int n = nums.length;

    for (int i = 0; i < n - 2; i++) {
        if (nums[i] > 0) break;
        if (i > 0 && nums[i] == nums[i - 1]) continue;

        int left = i + 1;
        int right = n - 1;
        while (left < right) {
            int sum = nums[i] + nums[left] + nums[right];
            if (sum < 0) {
                left++;
            } else if (sum > 0) {
                right--;
            } else {
                res.add(Arrays.asList(nums[i], nums[left], nums[right]));

                while (left < right && nums[left] == nums[left + 1]) left++;
                while (left < right && nums[right] == nums[right - 1]) right--;
                left++;
                right--;
            }
        }
    }
    return res;
}
```

## 按起点排序，维护尚未输出的一段

合并的是闭区间，故 [1,3] 和 [3,5] 可以接上。遇到重叠就取较大右端，包含关系 [1,8] 和 [2,3] 也成立；遇到间隙才输出当前段。循环结束仍有最后一段要补入。代码按原题至少有一个区间。

```java
public int[][] merge(int[][] intervals) {
    List<int[]> res = new ArrayList<>();
    Arrays.sort(intervals, (a, b) -> Integer.compare(a[0], b[0]));
    int start = intervals[0][0];
    int end = intervals[0][1];
    for (int i = 1; i < intervals.length; i++) {
        int nextStart = intervals[i][0];
        int nextEnd = intervals[i][1];
        if(nextStart<=end){
            end = Math.max(end,nextEnd);
        }
        else{
            res.add(new int[]{start,end});
            start = nextStart;
            end = nextEnd;
        }
    }
    res.add(new int[]{start, end});
    return res.toArray(new int[res.size()][]);
}
```

## 反转闭区间，组合成数组轮转

右移 k 位相当于把尾部 k 项搬到前面，两个块内部都要保持顺序。12345 右移 2 位，整体反转得到 54321，再分别反转 54 和 321。reverse 也能直接用在矩阵的一整行。题设数组非空。

```java
public void rotate(int[] nums, int k) {
    int n = nums.length;
    k %= n;
    reverse(nums, 0, n - 1);
    reverse(nums, 0, k - 1);
    reverse(nums, k, n - 1);

}

private void reverse(int[] nums, int left, int right) {
    while (left < right) {
        int temp = nums[left];
        nums[left] = nums[right];
        nums[right] = temp;
        left++;
        right--;
    }
}
```

## 让数值定位到自己的下标

长度 n 的数组有 n 个位置，可让 1 到 n 分别占下标 0 到 n-1。交换后当前格可能换来另一个可归位的数，要在原地下继续判断。先检查值域，再访问目标下标；目标已有同值就停，否则 [1,1] 会反复交换。每次有效交换至少归位一个新值，总时间 O(n)。

```java
public int firstMissingPositive(int[] nums) {
    int n = nums.length;
    for (int i = 0; i < n; i++) {
        // while 判断范围和目标位置，交换
        while (nums[i] >= 1 && nums[i] <= n && nums[i] != nums[nums[i] - 1]) {
            // 交换当前位置与目标位置
            int target = nums[i] - 1;
            int temp = nums[i];
            nums[i] = nums[target];
            nums[target] = temp;
        }
    }
    for (int i = 0; i < n; i++) {
        // 找第一个不匹配的位置
        if (nums[i] != i + 1) {
            return i + 1;
        }
    }
    return n + 1;
}
```
