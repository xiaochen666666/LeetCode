# 滑动窗口与单调队列

[返回常用代码索引](00%20常用代码索引.md)

先决定左端何时移动。固定窗口由长度决定；求最长时让窗口恢复合法再计长度；求最短覆盖时每次缩小之前都记录一个合法解。

## 定长窗口，数清进来与离开的字符

以 right 为新右端，旧窗口离开的下标是 right-m，新窗口左端是 right-m+1。先入，再按需移出，窗口足长才比较。s = abab、p = ab 时，起点 0、1、2 都要记录，匹配后窗口仍然只向右挪一格。数组长度 26 适用于题目的小写英文字母。

```java
public List<Integer> findAnagrams(String s, String p) {
    List<Integer> res = new ArrayList<>();
    int n = s.length(), m = p.length();
    if (n < m) return res;

    int[] target = new int[26], window = new int[26];
    for (int i = 0; i < m; i++) {
        target[p.charAt(i) - 'a']++;
    }

    for (int right = 0; right < n; right++) {
        window[s.charAt(right) - 'a']++;

        if (right >= m) {
            window[s.charAt(right - m) - 'a']--;
        }

        if (right >= m - 1 && Arrays.equals(target, window)) {
            res.add(right - m + 1);
        }
    }
    return res;
}
```

## 不定长窗口，排除冲突后记录最长

加入字符前，如果集合里已有它，就从左边逐个删，直到旧的同字符离开。对 abba，第二个 b 到来时，要先删 a 再删旧 b。迁移到异位词题时，可用频次数组表示每种字符还允许几个；某字母超额就缩窗，恢复后若长度等于目标长度便得到一个起点。两端各扫描一遍。

```java
public int lengthOfLongestSubstring(String s) {
    Set<Character> set = new HashSet<>();
    int left = 0;
    int res = 0;

    for (int right = 0; right < s.length(); right++) {
        char c = s.charAt(right);

        // 持续移除左侧字符，直到窗口中不再有 c
        while (set.contains(c)) {
            set.remove(s.charAt(left));
            left++;
        }

        set.add(c);
        res = Math.max(res, right - left + 1);
    }

    return res;
}
```

## 不定长窗口，满足覆盖时尝试缩短

用 missing 表示还缺几个字符，重复需求也计入。右端进入前若余额为正，说明能补一个缺口；左端移出后若余额变正，就重新缺一个。对 s=BAAC、t=AAC，先记录 BAAC，再删掉多余的 B，仍然合法，于是更新为 AAC。代码按本题英文字母范围使用数组。

```java
String minWindow(String s, String t) {
    if (t.isEmpty()) return "";
    int[] need = new int[128];
    for (char c : t.toCharArray()) need[c]++;
    int missing = t.length(), left = 0, start = 0, best = Integer.MAX_VALUE;
    for (int right = 0; right < s.length(); right++) {
        char in = s.charAt(right);
        if (need[in] > 0) missing--;
        need[in]--;
        while (missing == 0) {
            if (right - left + 1 < best) {
                start = left;
                best = right - left + 1;
            }
            char out = s.charAt(left++);
            need[out]++;
            if (need[out] > 0) missing++;
        }
    }
    return best == Integer.MAX_VALUE ? "" : s.substring(start, start + best);
}
```

## 定长窗口求极值，队首取答案

队列存下标，下标递增，对应值递减。下标小于 left 的从队首删除；新数大于等于队尾值时，旧候选更早过期，可以从尾部删除。nums=[1,3,2]、k=2，3 到来时淘汰 1，2 到来时保留 3。每个下标入队一次、出队至多一次，时间 O(n)，空间 O(k)。

```java
public int[] maxSlidingWindow(int[] nums, int k) {
    Deque<Integer> deque = new ArrayDeque<>();
    int n = nums.length;
    int[] res = new int[n - k + 1];
    for (int right = 0; right < n; right++) {
        int left = right - k + 1;
        while (!deque.isEmpty() && deque.peekFirst() < left) {
            deque.pollFirst();
        }
        while (!deque.isEmpty() && nums[deque.peekLast()] <= nums[right]) {
            deque.pollLast();
        }
        deque.offerLast(right);
        if (right >= k - 1) {
            res[left] = nums[deque.peekFirst()];
        }
    }
    return res;
}
```
