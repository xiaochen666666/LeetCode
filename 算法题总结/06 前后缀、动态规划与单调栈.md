## 先存左侧贡献，再补右侧贡献

answer[i] 先表示 i 严格左侧的乘积。倒序时 suffix 是 i 严格右侧的乘积，因此先乘入答案，再把 nums[i] 纳入 suffix。对 [2,0,3]，中间位置得到 2×3=6，两端都得到 0。两个边界的空乘积均为 1。时间 O(n)，除输出外空间 O(1)。

```java
public int[] productExceptSelf(int[] nums) {
    int n = nums.length;
    int[] answer = new int[n];
    answer[0] = 1;
    int suffix = 1;
    for (int i = 1; i < n; i++) {
        answer[i] = answer[i - 1] * nums[i - 1];
    }
    for (int i = n - 1; i >= 0; i--) {
        answer[i] *= suffix;
        suffix *= nums[i];
    }
    return answer;
}
```

## 以当前位置结尾，接上或重新开始

包含当前位置且在此结束的非空子数组只有两种来源：从当前位置开始，或接上以前一位结尾的最优段。current 每次都必须包含当前值，res 才负责保存历史最好值。初始化为首元素，[-3,-2] 才会得到 -2。时间 O(n)，空间 O(1)。

```java
public int maxSubArray(int[] nums) {
    int current = nums[0];
    int res = nums[0];
    for (int i = 1; i < nums.length; i++) {
        current = Math.max(nums[i], current + nums[i]);
        res = Math.max(res, current);
    }
    return res;
}
```

## 用左右最高值逐格结算水深

当前位置水深等于左右最高值中较低者减去柱高，最高值包含本格。若左侧已见最高值不超过右侧已见最高值，右边已经有足够高的墙，左格答案就确定了。另一边同理。[2,0,3] 的中间格贡献 2。题设高度数组非空。

```java
public int trap(int[] height) {
    int left = 0, right = height.length - 1;
    int leftMax = height[0], rightMax = height[right];
    int res = 0;
    while (left < right) {
        if (leftMax > rightMax) {
            res += (rightMax - height[right]);
            right--;
            rightMax = Math.max(rightMax, height[right]);
        } else {
            res += (leftMax - height[left]);
            left++;
            leftMax = Math.max(leftMax, height[left]);
        }
    }
    return res;
}
```

## 单调栈等右边界出现，再结算一层

栈存柱子下标。遇到高于栈顶的右墙时，弹出低处，露出的新栈顶给出左墙。宽度取两墙之间的格数，高度取较矮墙超过底部的部分。[3,1,2,3] 先在 2 处填一格，再在末尾填上层的两格。对比窗口最大值：两题都从尾部淘汰候选，窗口还要从头部移除过期下标。

```java
public int trap(int[] height) {
    if (height == null || height.length < 3) {
        return 0;
    }

    Deque<Integer> stack = new ArrayDeque<>();
    int res = 0;

    for (int i = 0; i < height.length; i++) {
        while (!stack.isEmpty() && height[i] > height[stack.peek()]) {
            int mid = stack.pop();

            if (stack.isEmpty()) {
                break;
            }

            int left = stack.peek();
            int width = i - left - 1;
            int boundedHeight = Math.min(height[left], height[i]) - height[mid];
            res += width * boundedHeight;
        }

        stack.push(i);
    }

    return res;
}
```
