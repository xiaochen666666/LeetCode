## 忘记解法时怎么复习

1. 先读每篇开头的“30 秒速记”，回想整条思路。
2. 想不起某一步，就沿“从题意一步步推导”阅读对应原因。
3. 跟着一个小例子手推，检查变量、指针或计数的变化。
4. 再看 Java 代码，理解每句对应哪一步。
5. 合上代码回答末尾自测，能讲清理由后再尝试自己写。

易错点记录的是算法误解及反例；集合方法另列在 Java 部分，便于从想法翻译成代码。
历史运行、平台通过和静态审阅分开说明，不把“整理完成”当作“平台通过”。

## 用学过的题互相回忆

- [两数之和](两数之和.md) → [三数之和](三数之和.md)：先固定一个数，剩下两个的目标就确定了。
- [字母异位词分组](字母异位词分组.md) → [找到字符串中所有字母异位词](找到字符串中所有字母异位词.md)：频次相同是共同判断标准，后者还要求在原串中连续。
- [无重复字符的最长子串](无重复字符的最长子串.md) → [找到字符串中所有字母异位词](找到字符串中所有字母异位词.md)：都可右扩左缩，前者限制每种字符最多 1 次，后者允许达到 p 给出的次数。
- [盛最多水的容器](盛最多水的容器.md) → [接雨水](接雨水.md)：都受较低边界约束，但前者选择两条线，后者累加柱子上方的水量，公式不能直接混用。
