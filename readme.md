# LeetCode 学习笔记

这里记录我用 Java 学习 LeetCode 的过程。笔记重点是：从题意中发现什么条件、为什么选择这种数据结构、怎样一步步推导到代码。

整理日期：2026-10-30，共 14 篇题目笔记。每篇保留已完成的方法、代码、关键误区和验证范围。

## 忘记解法时怎么复习

1. 先读每篇开头的“30 秒速记”，回想整条思路。
2. 想不起某一步，就沿“从题意一步步推导”阅读对应原因。
3. 跟着一个小例子手推，检查变量、指针或计数的变化。
4. 再看 Java 代码，理解每句对应哪一步。
5. 合上代码回答末尾自测，能讲清理由后再尝试自己写。

易错点记录的是算法误解及反例；集合方法另列在 Java 部分，便于从想法翻译成代码。
历史运行、平台通过和静态审阅分开说明，不把“整理完成”当作“平台通过”。

## 已记录的方法

| 题目 | 方法 |
| --- | --- |
| 两数之和 | 哈希表查询补数 |
| 无重复字符的最长子串 | 不定长滑窗 + HashSet |
| 盛最多水的容器 | 双指针，按可排除边界移动 |
| 三数之和 | 排序 + 固定一个数 + 双指针 + 去重 |
| 接雨水 | 方法一：前后缀最高值数组；方法二：双指针；方法三：单调栈 |
| 字母异位词分组 | 排序标识 + 哈希表分组 |
| 最大子数组和 | Kadane；前缀和 + 最小历史前缀；四信息分治 |
| 合并区间 | 按左端点排序 + 扫描合并 |
| 最小覆盖子串 | 不定长滑窗：频次扫描；diff + 达标种类数优化 |
| 最长连续序列 | HashSet 起点扩展；提前返回；端点差计算长度 |
| 滑动窗口最大值 | 逐窗口扫描；单调队列；最大堆懒删除；分块前后缀最大值 |
| 移动零 | 双指针原地交换；覆盖后补零的思路对照 |
| 找到字符串中所有字母异位词 | 方法一：定长滑窗；方法二：不定长滑窗 |
| 和为 K 的子数组 | 方法一：枚举左右端点；方法二：前缀和 + 哈希表 |

## 用学过的题互相回忆

- [两数之和](两数之和.md) → [三数之和](三数之和.md)：先固定一个数，剩下两个的目标就确定了。
- [字母异位词分组](字母异位词分组.md) → [找到字符串中所有字母异位词](找到字符串中所有字母异位词.md)：频次相同是共同判断标准，后者还要求在原串中连续。
- [无重复字符的最长子串](无重复字符的最长子串.md) → [找到字符串中所有字母异位词](找到字符串中所有字母异位词.md)：都可右扩左缩，前者限制每种字符最多 1 次，后者允许达到 p 给出的次数。
- [盛最多水的容器](盛最多水的容器.md) → [接雨水](接雨水.md)：都受较低边界约束，但前者选择两条线，后者累加柱子上方的水量，公式不能直接混用。
